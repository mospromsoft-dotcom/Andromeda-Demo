# Сторонние компоненты и ресурсы

Space2D 1.3.0 использует SDL 3.4.16 (zlib license) и библиотеки исполнения LLVM-MinGW: libc++, libunwind и winpthreads. Тексты лицензий находятся в папке `licenses` игрового архива.

- [Исходники SDL 3.4.16](https://github.com/libsdl-org/SDL/tree/release-3.4.16).
- [Комплект LLVM-MinGW 20260908](https://github.com/mstorsjo/llvm-mingw/releases/tag/20260908).

Загрузка PNG использует Windows Imaging Component. Атлас текста создаётся при запуске из установленного системного Segoe UI; файл шрифта не распространяется.

38 радиореплик на русском и английском созданы локально через Windows System.Speech голосами Microsoft Irina Desktop и Microsoft Zira Desktop и обработаны под радиосвязь. В демосборке находятся готовые PCM WAV 48 kHz / 16 bit / mono; файлы голосового движка и синтезатор не включены. Это временная озвучка прототипа. Боевые эффекты и окружающий гул синтезируются кодом игры.

Растровые изображения кораблей, станций, планет, модулей, астероидов, туманности, четырёх интерьеров и восьми портретов NPC созданы встроенным image_gen для проекта. Генерация не является заявлением об исключительных правах на изображения.
